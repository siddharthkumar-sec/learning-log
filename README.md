1. **Learn:** Understand the concepts and underlying principles.
2. **Practice:** Solve exercises and implement what I learn.
3. **Experiment:** Explore different approaches and test ideas.
4. **Document:** Record explanations, examples and observations.
5. **Improve:** Review mistakes, refine understanding and build further.

I prioritize conceptual understanding over memorization.
