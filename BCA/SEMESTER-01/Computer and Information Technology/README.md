## About This Subject

Computer and Information Technology is one of the foundational subjects in my BCA Semester 01 curriculum.

This subject introduces the fundamental concepts behind computers, information systems, operating systems, digital logic, networking, and the World Wide Web.

I use this directory to maintain module-wise study notes and practice resources in one organized location.

**My learning objective:** Understand how computers process information, how operating systems manage resources, and how modern computing systems communicate.

Through this subject, I aim to develop an understanding of the following areas:

| DOMAIN | LEARNING OBJECTIVE |
|:---|:---|
| 🖥️ Computer Fundamentals | Understand computer components, characteristics, and basic operations. |
| 🔢 Number Systems | Learn number representations and conversions. |
| 🔐 Boolean Logic | Understand logical operations and digital fundamentals. |
| ⚙️ Operating Systems | Learn OS functions, components, and resource management. |
| 🌐 Networking | Understand data communication and computer networks. |
| 💻 Programming | Develop an understanding of programming fundamentals. |
| 🌍 Internet & WWW | Learn how the Internet and World Wide Web work. |

### Connection With My Technical Roadmap

The concepts learned in this subject provide a foundation for future technical domains:

- **Operating Systems →** Linux and system administration.
- **Data Communication →** Computer networking.
- **Number Systems & Boolean Logic →** Digital systems and computing fundamentals.
- **Programming Fundamentals →** Python and software development.
- **Internet & WWW →** Web technologies and cloud infrastructure.

- Focus on why and how things work.
- Practise different question patterns.
- Identify mistakes instead of memorizing incorrect answers.
- Revise important concepts regularly.
