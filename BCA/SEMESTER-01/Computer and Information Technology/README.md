## 01 / SUBJECT OVERVIEW

Computer & Information Technology introduces the fundamental concepts that form the foundation of modern computing.

This subject is an important part of my BCA Semester 01 curriculum. It helps me understand how computers operate, how information is processed, how operating systems manage resources, and how digital systems communicate.

I maintain this repository to organize my study materials, access module-wise notes, and practise important questions.

## 04 / LEARNING OBJECTIVES

The subject covers several important areas of computing.

| TECHNICAL AREA | WHAT I AIM TO UNDERSTAND |
|:---|:---|
| 🖥️ Computer Fundamentals | Computer components, characteristics, and operations |
| 🔢 Number Systems | Binary, decimal, octal, hexadecimal, and conversions |
| 🔐 Boolean Logic | Logical operations and digital fundamentals |
| ⚙️ Operating Systems | OS functions, components, and resource management |
| 🌐 Data Communication | Communication systems and networking concepts |
| 💻 Programming Fundamentals | Basic programming concepts and logic |
| 🌍 Internet & WWW | Internet architecture and web technologies |

These concepts provide the theoretical foundation for understanding more advanced technologies.
